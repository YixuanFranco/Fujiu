Claude Code 一步安装与验证

适用于 macOS、Linux、Windows。按步骤执行即可完成安装与登录。

🚀 1. 安装 Claude Code（Node.js + npm）

第一步：安装 Node.js

请先打开以下地址下载安装包并完成安装：

  • https://nodejs.cn/download/
建议安装 LTS 版本，安装完成后重开终端。

第二步：通过 npm 安装 Claude Code

npm install -g @anthropic-ai/claude-code
安装后如果提示命令不存在，请确认 Node.js 与 npm 已正确安装并加入 PATH。

# Claude Code 配置

## 环境变量

macOS（当前终端临时生效）：

export ANTHROPIC_AUTH_TOKEN=sk-你的密钥 export ANTHROPIC_BASE_URL="https://fujiuapi.com"

macOS（永久生效，写入 ~/.zshrc）：

echo 'export ANTHROPIC_AUTH_TOKEN=sk-你的密钥' >> ~/.zshrc echo 'export ANTHROPIC_BASE_URL="https://fujiuapi.com"' >> ~/.zshrc source ~/.zshrc
这些变量只对终端生效。写进 ~/.zshrc 的 export 只有你在终端里敲 claude 时才读得到。如果你用的是图形界面客户端（从 Dock / 启动台点图标启动），它由系统 launchd 拉起、全程不经过 zsh，会提示读不到密钥。两个办法：一是改用 launchctl setenv ANTHROPIC_AUTH_TOKEN "sk-你的密钥"（ANTHROPIC_BASE_URL 同理），设完彻底退出客户端再重开；二是把配置写进 ~/.claude/settings.json 的 env 字段，终端和图形界面都能读到。
注意 ANTHROPIC_BASE_URL 结尾不要带斜杠。Claude Code 会自己拼接 /v1/messages，多一个斜杠会拼成 //v1/messages，部分网关会返回 404。

Windows：

setx ANTHROPIC_AUTH_TOKEN "sk-你的密钥" setx ANTHROPIC_BASE_URL "https://fujiuapi.com"

## 指定模型（必做）

Claude Code 默认请求的模型 ID 在中转站不存在，不指定会直接报 404。这三行和上面的密钥、地址一样要设置好。

macOS：

echo 'export ANTHROPIC_DEFAULT_OPUS_MODEL="claude-opus-5"' >> ~/.zshrc echo 'export ANTHROPIC_DEFAULT_SONNET_MODEL="claude-sonnet-5"' >> ~/.zshrc echo 'export ANTHROPIC_DEFAULT_HAIKU_MODEL="claude-haiku-4-5-20251001-thinking"' >> ~/.zshrc source ~/.zshrc

Windows：

setx ANTHROPIC_DEFAULT_OPUS_MODEL "claude-opus-5" setx ANTHROPIC_DEFAULT_SONNET_MODEL "claude-sonnet-5" setx ANTHROPIC_DEFAULT_HAIKU_MODEL "claude-haiku-4-5-20251001-thinking"

## 先验接口（强烈建议）

变量配好后，先用一条 curl 确认密钥和接口是通的，再去开 Claude Code。这一步能把「密钥 / 套餐问题」和「客户端配置问题」分开——直接启动 Claude Code 报错，你分不清是哪一边的毛病，很容易白折腾半天。

curl https://fujiuapi.com/v1/messages \ -H "Authorization: Bearer $ANTHROPIC_AUTH_TOKEN" \ -H "anthropic-version: 2023-06-01" \ -H "content-type: application/json" \ -d '{ "model": "claude-sonnet-5", "max_tokens": 64, "messages": [{"role":"user","content":"你好"}] }'

返回下面这样就说明通了，可以放心去配客户端：

{"id":"msg_xxx","type":"message","role":"assistant", "content":[{"type":"text","text":"你好！..."}], "stop_reason":"end_turn","model":"claude-sonnet-5", ... }
报错对照：
401 —— 密钥错误或已过期，检查 echo $ANTHROPIC_AUTH_TOKEN 打出来的值有没有多余空格或引号。
403 —— 余额不足，去钱包页充值。
404 —— 模型名有误，或地址写错了。注意这个接口是 /v1/messages，不是 OpenAI 协议的 /v1/chat/completions。
400 —— 多半是漏了 max_tokens。Anthropic 协议里它是必填的，和 OpenAI 协议不一样。
别用「你是什么模型」来验证。模型的自我描述并不可靠，经常说错自己的版本号。要确认这次请求实际用的是哪个模型，看返回 JSON 里的 model 字段，那个才是准的。

设置完成后启动一次 Claude Code：

claude

🎯 安装完就可以开始了
