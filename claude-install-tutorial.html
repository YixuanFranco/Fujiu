Claude Code 一步安装与验证

适用于 macOS、Linux、Windows。按步骤执行即可完成安装与登录。

🚀 1. 安装 Claude Code（Node.js + npm）

第一步：安装 Node.js

请先打开以下地址下载安装包并完成安装：

  • https://nodejs.cn/download/
建议安装 LTS 版本，安装完成后重开终端。

第二步：通过 npm 安装 Claude Code

npm install -g @anthropic-ai/claude-code
安装后如果提示命令不存在，请确认 Node.js 与 npm 已正确安装并加入 PATH。

# Claude Code 配置

## 环境变量

macOS（当前终端临时生效）：

export ANTHROPIC_AUTH_TOKEN=你的密钥 export ANTHROPIC_BASE_URL="https://fujiuapi.com/"

macOS（永久生效，写入 ~/.zshrc）：

echo 'export ANTHROPIC_AUTH_TOKEN=你的密钥' >> ~/.zshrc echo 'export ANTHROPIC_BASE_URL="https://fujiuapi.com/"' >> ~/.zshrc source ~/.zshrc

Windows：

setx ANTHROPIC_AUTH_TOKEN "你的密钥" setx ANTHROPIC_BASE_URL "https://fujiuapi.com/"

设置完成后启动一次 Claude Code：

claude

🎯 安装完就可以开始了
