# Claude Code 配置

## 环境变量

**macOS（当前终端临时生效）：**
```bash
export ANTHROPIC_AUTH_TOKEN=你的密钥
export ANTHROPIC_BASE_URL="https://www.yuesei.com/api"
```

**macOS（永久生效，写入 ~/.zshrc）：**
```bash
echo 'export ANTHROPIC_AUTH_TOKEN=你的密钥' >> ~/.zshrc
echo 'export ANTHROPIC_BASE_URL="https://www.yuesei.com"' >> ~/.zshrc
source ~/.zshrc
```

**Linux：**
```bash
export ANTHROPIC_AUTH_TOKEN=你的密钥
export ANTHROPIC_BASE_URL="https://www.yuesei.com"
```

**Windows：**
```cmd
setx ANTHROPIC_AUTH_TOKEN "你的密钥"
setx ANTHROPIC_BASE_URL "https://www.yuesei.com"
```
