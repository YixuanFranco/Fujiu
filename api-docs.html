扶九API 接入文档

OpenAI 兼容协议，三分钟接入全球主流 AI 大模型

📌 一、基础信息

API 地址
https://fujiuapi.com 或 https://fujiuapi.com/v1
鉴权方式
HTTP Header Authorization: Bearer <API_KEY>
兼容协议
OpenAI API 协议（可直接替换 base_url 接入）
数据格式
JSON
💡 提示：扶九API 完全兼容 OpenAI 协议，任何支持自定义 base_url 的客户端（如 OpenCode、Cursor、Claude Code、Codex、Dify、FastGPT 等）均可直接使用。
🔧 关于 API 地址：部分客户端需要填 https://fujiuapi.com，部分需要填 https://fujiuapi.com/v1。如果一个报错，请换另一个试试。

🚀 二、快速开始

1

注册并登录

访问 fujiuapi.com/sign-up 注册账号并登录。

2

创建 API 密钥

进入「API 密钥」页面，点击「+ 创建 API 密钥」。

  • 名称：随便填写，方便识别即可
  • 分组：推荐选择 vip（3 倍倍率，费率最划算）
  • 过期时间：取决于你购买的套餐有效期（如日卡 3 天、月卡 30 天等），密钥会随套餐到期
3

复制密钥并使用

创建后复制 sk- 开头的密钥，在客户端中填入 API 地址和密钥即可。

🔧 三、核心接口

1. 获取模型列表

# 请求
GET https://fujiuapi.com/v1/models
Authorization: Bearer 你的API_KEY

2. 聊天补全（Chat Completions）

# 请求
POST https://fujiuapi.com/v1/chat/completions
Authorization: Bearer 你的API_KEY
Content-Type: application/json

{
  "model": "claude-sonnet-5",
  "messages": [
    {"role": "user", "content": "你好"}
  ]
}

3. 流式输出（SSE）

在请求体中加上 "stream": true，服务端会以 SSE（Server-Sent Events）格式逐字返回结果。

{
  "model": "claude-sonnet-5",
  "messages": [{"role": "user", "content": "你好"}],
  "stream": true
}

4. 文本补全（Completions）

POST https://fujiuapi.com/v1/completions
Authorization: Bearer 你的API_KEY

{
  "model": "gpt-4o-mini",
  "prompt": "你好",
  "max_tokens": 100
}

5. Anthropic 原生协议（Messages）

除 OpenAI 协议外，本站同时提供 Anthropic 原生 /v1/messages 接口，供 Claude Code、Anthropic 官方 SDK 等只认原生协议的客户端使用。

POST https://fujiuapi.com/v1/messages
Authorization: Bearer 你的API_KEY
anthropic-version: 2023-06-01
Content-Type: application/json

{
  "model": "claude-sonnet-5",
  "max_tokens": 1024,
  "messages": [
    { "role": "user", "content": "你好" }
  ]
}
与 OpenAI 协议的三个差异：
1. max_tokens 是必填项，漏了会返回 400。OpenAI 协议里它是可选的。
2. 需要额外带 anthropic-version: 2023-06-01 请求头。
3. 返回结构不同：正文在 content[0].text，不是 choices[0].message.content。
流式同样是在请求体里加 "stream": true，按 SSE 返回。本接口只接受 claude 系模型。

💻 四、代码示例

🔧 base_url 填写说明：以下示例中的 base_url / baseURL 可以填 https://fujiuapi.com 或 https://fujiuapi.com/v1，如果一个报错请换另一个。

cURL

curl https://fujiuapi.com/v1/chat/completions \
  -H "Authorization: Bearer sk-你的密钥" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "claude-sonnet-5",
    "messages": [{"role": "user", "content": "你好"}]
  }'

Python（openai 库）

from openai import OpenAI

client = OpenAI(
    api_key="sk-你的密钥",
    base_url="https://fujiuapi.com"
)

resp = client.chat.completions.create(
    model="claude-sonnet-5",
    messages=[{"role": "user", "content": "你好"}]
)
print(resp.choices[0].message.content)

Node.js

const OpenAI = require("openai");

const client = new OpenAI({
  apiKey: "sk-你的密钥",
  baseURL: "https://fujiuapi.com"
});

async function run() {
  const resp = await client.chat.completions.create({
    model: "claude-sonnet-5",
    messages: [{ role: "user", content: "你好" }]
  });
  console.log(resp.choices[0].message.content);
}
run();

Claude Code 配置

# 设置环境变量（Linux / macOS）
export ANTHROPIC_AUTH_TOKEN=sk-你的密钥
export ANTHROPIC_BASE_URL=https://fujiuapi.com
export ANTHROPIC_DEFAULT_OPUS_MODEL=claude-opus-5
export ANTHROPIC_DEFAULT_SONNET_MODEL=claude-sonnet-5
export ANTHROPIC_DEFAULT_HAIKU_MODEL=claude-haiku-4-5-20251001-thinking

# Windows PowerShell
$env:ANTHROPIC_AUTH_TOKEN="sk-你的密钥"
$env:ANTHROPIC_BASE_URL="https://fujiuapi.com"
$env:ANTHROPIC_DEFAULT_OPUS_MODEL="claude-opus-5"
$env:ANTHROPIC_DEFAULT_SONNET_MODEL="claude-sonnet-5"
$env:ANTHROPIC_DEFAULT_HAIKU_MODEL="claude-haiku-4-5-20251001-thinking"
⚠️ 三个要点：
1. 用 ANTHROPIC_AUTH_TOKEN，不要用 ANTHROPIC_API_KEY。前者以 Authorization: Bearer 发送，后者发的是 x-api-key，本站认前者。
2. ANTHROPIC_BASE_URL 结尾不要带斜杠。Claude Code 会自己拼接 /v1/messages，多一个斜杠可能导致 404。
3. 三个模型变量必须设置。Claude Code 默认请求的模型 ID 在本站不存在，不指定会直接 404。且只能填 claude 系模型，gpt / qwen / glm 等填进来不会生效。
完整安装步骤见 Claude Code 安装教程。

Codex 配置

Codex 不读环境变量里的接口地址，需要写配置文件。新建 ~/.codex/config.toml：

model = "gpt-6-astra"
model_provider = "fujiu"

[model_providers.fujiu]
name = "扶九API"
base_url = "https://fujiuapi.com/v1"
env_key = "FUJIU_API_KEY"
wire_api = "responses"

再把密钥存进 env_key 指定的环境变量：

# Linux / macOS
export FUJIU_API_KEY=sk-你的密钥

# Windows PowerShell
$env:FUJIU_API_KEY="sk-你的密钥"
⚠️ 三个要点：
1. wire_api 必须是 "responses"。新版 Codex 已移除对 "chat" 的支持，填 "chat" 会在加载配置阶段直接报错退出。
2. base_url 这里要带 /v1，和 Claude Code 不同。Codex 会在其后拼接 /responses。
3. 只能填 gpt- / o 开头的 OpenAI 系模型。Codex 走 Responses 协议，claude、qwen、glm 等填进来会报错。
完整安装步骤见 Codex 闯关教程。

❓ 五、常见问题

Q1：如何查看账户余额？

登录后进入「钱包」页面，可查看当前余额、消费记录和充值。

Q2：分组（倍率）是什么意思？

不同分组对应不同的计费倍率：

  • vip：3 倍倍率，性价比最高，推荐日常使用
  • svip：4 倍倍率，适合高频调用
  • default：1 倍倍率，标准费率

创建 API 密钥时选择对应分组即可，分组决定该密钥的计费倍率。

Q4：API 密钥忘记保存了怎么办？

API 密钥只在创建时完整显示一次。如果丢失，删除旧密钥并重新创建一个即可。

Q5：调用报错怎么办？

  • 401 Unauthorized：密钥错误或已过期，请检查密钥是否正确
  • 403 Forbidden：余额不足，请充值后重试
  • 404 Not Found：模型名称错误，请到模型广场确认模型名称
  • 429 Too Many Requests：请求过于频繁，请降低调用频率
