扶九API 使用教程

三步获取你的 API 密钥，即可接入全球主流 AI 大模型

1

进入「API 密钥」页面

登录扶九API 控制台后，点击左侧菜单的「API 密钥」，或直接访问：

🔑 前往 API 密钥页面
2

创建 API 密钥

点击右上角的「+ 创建 API 密钥」按钮，在弹出的表单中填写：

名称 随便填写，方便你自己识别即可（如「我的key」）
分组 选择 vip（费率更划算，3倍倍率）
过期时间 默认「永不过期」即可
数量 默认 1 个
💡 分组选择提示：不同分组对应不同的费率倍率。
• vip 分组：3 倍倍率，性价比最高，推荐日常使用
• svip 分组：4 倍倍率，适合高频调用场景
• default 分组：1 倍倍率，标准费率
3

复制并使用 API 密钥

创建成功后，列表中会显示新生成的密钥（以 sk- 开头），点击复制按钮保存。

在任意支持 OpenAI 协议的客户端（如 OpenCode、Cursor、Claude Code 等）中填入以下信息：

Base URL（API 地址）：https://fujiuapi.com
API Key：sk-你复制的密钥
模型名称：去「模型广场」查看可用模型
⚠️ 注意：API 密钥只在创建时完整显示一次，请妥善保管。如需查看可用的模型列表，前往「模型广场」，模型会持续更新。
