Cursor 扶九API配置指南

通过扶九API 在 Cursor 中使用 Claude 模型，享受更优质的服务

1

购买 Cursor Pro 账号

前往淘宝购买一个没有额度的 Cursor Pro 账号（共享号）。

作者购买的是 25 元的共享号，性价比很高。

💡 为什么选择无额度的 Pro 号？

  • Cursor Pro 原生只有 20 美金额度，使用扶九API 可以获得更多额度
  • 共享号价格便宜，配合扶九API使用更划算
2

获取扶九API Key

确保你已经拥有扶九API 的 API Key。

如果没有，请联系 QQ 2306309941（或扫码添加企业微信客服）获取扶九API服务。

3

配置 Cursor 设置

打开 Cursor 设置，按照下图进行配置：

Cursor 设置配置示例
4

填写 API 地址

在 Cursor 设置中填写以下 API 地址：

https://fujiuapi.com/v1
5

添加模型

在模型设置中添加以下模型（至少添加一个）：

claude-opus-4-6

如果想省钱，可以添加：

claude-sonnet-4-6

建议：两个都添加并开启，这样可以根据需要切换使用。

模型添加示例

🎉 配置完成！

现在你可以在 Cursor 中使用扶九API 了
