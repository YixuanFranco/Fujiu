Codex 是什么？为什么值得玩

Codex 是 OpenAI 官方推出的命令行 AI 编程智能体：你在终端里用大白话下指令，它直接读你的文件、写代码、改文档、跑命令——像一个住在电脑里的全能实习生。

官方用法要绑定 ChatGPT Plus/Pro 账号（$20/月起）。但 Codex 支持自定义接口——把接口指向 扶九API，用按量付费的 API Key 就能跑，几分钱起步，模型随便换。

本教程两件事：① 把 Codex 接上扶九API（5 分钟）；② 送你一套「十关关卡包」，跟着 AI 教练一关一关玩下来，顺便把真活干了。
1

装前置环境（Node.js）

Codex 通过 npm 安装，需要 Node.js 18 或更高版本。

  • Mac 用户：打开「终端」（启动台搜 terminal），先装 Node.js LTS 版，或用 Homebrew：brew install node
  • Windows 用户：建议先装 WSL（Windows 内置的 Linux 子系统）。以管理员身份打开 PowerShell，输入：
wsl --install

装完重启电脑，开始菜单出现 Ubuntu，打开它（第一次会让你设个用户名和密码），后面所有命令都在这个窗口里敲。

2

安装 Codex

打开终端（Windows 用户打开 Ubuntu 窗口），复制粘贴这行，回车：

npm install -g @openai/codex

跑完后输入 codex --version，能打印版本号就说明装好了。

提示「npm 不是内部或外部命令」？说明 Node.js 没装好——回到步骤 1 重装，装完关掉终端重新打开再试。
3

获取你的扶九API Key

  1. 打开 fujiuapi.com，登录（没账号先注册，充值套餐开通额度）
  2. 进入 控制台 → 令牌，点「添加令牌」
  3. 分组建议选 vip（价格更优），创建后复制以 sk- 开头的密钥
Key 就是你的钱包钥匙：不要发给别人、不要传到网上。泄露了立刻回控制台删除重建。
4

把 Codex 接上扶九API（核心步骤）

4.1 配置接口。在终端里依次执行（一次一行）：

mkdir -p ~/.codex
nano ~/.codex/config.toml

在打开的编辑器里粘贴以下内容，然后按 Ctrl+O 回车保存、Ctrl+X 退出：

model = "gpt-6-astra"
model_provider = "fujiu"

[model_providers.fujiu]
name = "扶九API"
base_url = "https://fujiuapi.com/v1"
env_key = "FUJIU_API_KEY"
wire_api = "responses"
最后一行必须是 wire_api = "responses"。早期版本的本教程写的是 wire_api = "chat"，新版 Codex 已经不再支持该值，照旧配置会导致 codex 直接启动失败。如果你之前配过，把这一行改掉即可。

4.2 存入你的 Key。把下面命令里的 sk-你的密钥 换成步骤 3 复制的 Key，执行：

# Mac 用户：
echo 'export FUJIU_API_KEY="sk-你的密钥"' >> ~/.zshrc && source ~/.zshrc

# Windows 用户（WSL 窗口里）：
echo 'export FUJIU_API_KEY="sk-你的密钥"' >> ~/.bashrc && source ~/.bashrc
用 Codex 桌面 App 的话请注意：这一步写进 ~/.zshrc 的变量只对终端生效。从 Dock / 启动台点图标启动的桌面 App 读不到它，会报 Missing environment variable: FUJIU_API_KEY——解决办法见文末常见问题第一条。
想换模型？改 config.toml 第一行即可，比如 model = "gpt-5.3-codex"、"gpt-5-codex"、"gpt-5.5"，全是扶九API 已上线的模型。
5

验收：跑通第一句话

mkdir -p ~/codex-test && cd ~/codex-test
codex

进入对话界面后，直接打字：帮我创建一个 hello.txt，内容写"扶九API，起飞"，回车。它会请求权限（选允许），然后你会在目录里看到这个文件——恭喜，通了！

首次启动若弹出登录引导：我们走的是自己的接口，不需要 ChatGPT 账号——按提示跳过 / 选择使用 API Key 即可。
跑不动了？按 Esc 随时让它停下。花多少钱随时在 控制台 → 日志 / 钱包 里看，一分一笔都清楚。
6

进入十关：下载关卡包，开玩

「十关关卡包」是一个游戏化训练场：解压到桌面，在里面启动 Codex，它会化身闯关教练——你说「开始」「继续」「急救」，它带你一关一关过，每关送你一个通关口令。从写第一封邮件到整理乱成一团的文件夹，学完直接用在真活上。

常见问题急救

终端里 codex 能用，Codex 桌面 App 却报 Missing environment variable: FUJIU_API_KEY

不是 Key 配错了，是 App 压根读不到它。~/.zshrc 只在终端启动 shell 时被读取；而从 Dock、启动台、访达点图标启动的 App 由系统的 launchd 拉起，全程不经过 zsh，所以拿不到你 export 的变量。config.toml 是两边共用的，所以 base_url、model 都正常，唯独 Key 因为存在环境变量里而断了。

办法一（最快）：从终端敲 codex app 启动。这样 App 是终端 shell 的子进程，会直接继承环境变量。

办法二（以后点图标也能用）：把 Key 交给 launchd，然后 Cmd+Q 彻底退出 Codex App 再重开（只关窗口不算，必须退进程）：

launchctl setenv FUJIU_API_KEY "sk-你的密钥"

敲 launchctl getenv FUJIU_API_KEY 能打印出 Key 就说明写进去了。此法重启电脑后失效；想开机自动生效，把这条命令做成 ~/Library/LaunchAgents/ 下的 LaunchAgent 开机运行即可。

启动就报 Error loading config.toml: `wire_api = "chat"` is no longer supported.

新版 Codex 已移除对 Chat Completions 协议的支持，只走 Responses 协议。打开 ~/.codex/config.toml，把最后一行改成：

wire_api = "responses"

改完保存即可，其余几行不用动。（本教程早期版本给的是 "chat"，在旧版 Codex 上能用，升级后就会报这个错。）

报错 401 / Unauthorized

Key 没配对：检查第 4.2 步的环境变量名是不是 FUJIU_API_KEY、Key 有没有多余的空格，改完关掉终端重开再试。

连接失败 / timeout

检查 config.toml 里 base_url 必须是 https://fujiuapi.com/v1（结尾带 /v1），保存后重开 codex。

Windows 提示「npm 不是内部或外部命令」

Node.js 没装好或终端没重开。推荐直接用 WSL（步骤 1），体验和 Mac 一致。

想换更便宜 / 更强的模型

改 config.toml 的 model 字段。编程推荐 gpt-6-astra / gpt-5.3-codex / gpt-5-codex；想省钱可用 gpt-5-mini、gpt-5.4-nano。

注意：Codex 只走 Responses 协议，因此只能填 gpt- / o 开头的 OpenAI 系模型。模型广场里的 claude、qwen、glm、deepseek 等虽然扶九API 都支持，但那是 OpenAI Chat 协议下的模型，填进 Codex 会报错。要用 Claude 系模型请走 Claude Code 教程。

怎么查看消耗了多少钱

登录 fujiuapi.com → 控制台 → 日志，每次调用、每个 token 都有明细。
