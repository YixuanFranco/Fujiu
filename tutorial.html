配置 MCP：打开用户配置

第一步：打开命令面板

  • Windows/Linux: Ctrl + Shift + P
  • macOS: Cmd + Shift + P

第二步：搜索并打开配置

  1. 搜索 mcp
  2. 选择 "用户配置 / User Configuration"（名称可能略有差异，以界面为准）
  3. 打开并编辑 mcp.json

第三步：输入配置代码

{ "servers": { "mcp-ai-forever": { "command": "uvx", "args": [ "mcp-ai-forever@latest" ], "autoApprove": [ "interactive_feedback" ] } } }

⚠️ 第一次安装会出现缺少 uvx 错误

右下角会弹出错误提示，点击后会进入如下网址：

https://docs.astral.sh/uv/getting-started/installation/

🔔 网络提示

网络可能比较慢，需要多下载几次，请耐心等待。

补充设置：配置 VSCode 设置

如果没有出现 Claude Code，需要进行以下设置：

第一步：打开设置

  1. 点击左下角的 齿轮图标 (设置)
  2. 搜索 setting
  3. 选择 "打开用户设置(JSON)"

第二步：替换配置

将以下配置复制并粘贴到你的 settings.json 文件中：

{ "editor.formatOnSave": true, "http.proxy": "http://127.0.0.1:7897", "editor.fontSize": 16, "editor.fontLigatures": false, "[dart]": { "editor.formatOnSave": true, "editor.formatOnType": true, "editor.rulers": [ 80 ], "editor.selectionHighlight": false, "editor.suggestSelection": "first", "editor.tabCompletion": "onlySnippets", "editor.wordBasedSuggestions": "off" }, "git.openRepositoryInParentFolders": "never", "chat.mcp.gallery.enabled": true, "css.format.enable": false, "github.copilot.nextEditSuggestions.enabled": true, "chat.tools.global.autoApprove": true, "chat.tools.terminal.autoApprove": { "rm": false, "sudo": false, "curl": true }, "explorer.confirmDelete": false, "github.copilot.enable": { "*": true, "plaintext": false, "markdown": true, "scminput": false }, "chat.mcp.serverSampling": {}, "chat.mcp.discovery.enabled": { "claude-desktop": true }, "chat.agent.maxRequests": 250000000000, "workbench.editor.pinnedTabsOnSeparateRow": true, "chat.instructionsFilesLocations": { ".github/prompts": true }, "remote.extensionKind": { "GitHub.copilot": [ "ui" ], "GitHub.copilot-chat": [ "ui" ], "pub.name": [ "ui" ] } }
