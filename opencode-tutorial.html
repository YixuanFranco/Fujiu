OpenCode 扶九API 使用教程

快速安装配置 OpenCode AI 助手，在 VSCode 中直接使用强大的 AI 能力，代码分析、智能补全、一站式开发体验。

1

安装 Node.js

访问 nodejs.cn 下载并安装 LTS 版本

node --version npm --version

验证安装：显示版本号即成功

2

安装 OpenCode CLI

打开终端（macOS 使用 Terminal，Windows 使用 PowerShell 或 CMD），执行以下命令：

npm install -g opencode-ai --registry=https://registry.npmmirror.com

验证安装：

opencode --version
3

安装 VSCode 扩展

在 VSCode 扩展商店搜索 opencodecat/opencodecat像素猫 并安装

💡 配置令牌

安装后，在扩展设置中输入从 https://fujiuapi.com 获取的令牌

分组说明：

• default：省流模式，适合日常使用

• vip：性价比最好，推荐选择

• svip：满血性能，价格较高

4

开始使用

🎉 安装完成

现在您可以在 VSCode 中使用 OpenCode + 扶九API 了！

!

常见问题：PowerShell 执行策略错误（Windows）

🐛 问题现象

在 PowerShell 中运行 npm install -g opencode-ai 时出现以下错误：

无法加载文件 C:\Program Files\nodejs\npm.ps1，因为在此系统上禁止运行脚本 有关详细信息，请参阅 https://go.microsoft.com/fwlink/?LinkID=135170

✅ 解决方案

以管理员身份运行 PowerShell，执行以下命令：

Set-ExecutionPolicy RemoteSigned -Scope CurrentUser

执行后重新运行安装命令即可。

💡 说明

此命令允许运行本地脚本和已签名的远程脚本，是 Windows 开发环境的标准配置。
